# Security Policy

## Reporting a vulnerability
Do not post secrets, student information, private URLs, exploit details, or sensitive logs in a public issue. Use GitHub private vulnerability reporting if enabled; otherwise open only a minimal issue until a private channel is established.

## Security expectations
- Never commit provider/API tokens.
- Do not collect or send student names, IEP/disability information, photos, grades, or other sensitive student data to remote AI services.
- Keep generated educational content clearly reviewable by an adult.
- Validate external data and model output before display/use.
- Bound AI/network calls with timeouts and safe fallbacks.
- Keep logs free of student-sensitive data.
